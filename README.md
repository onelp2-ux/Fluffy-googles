# AI Persona Generator

A simple tool to generate diverse personas for thinking through problems from different perspectives.

## How to Use (No Coding Required!)

### Step 1: Get an API Key
1. Go to [console.anthropic.com](https://console.anthropic.com/)
2. Sign up for a free account
3. Get your API key (it will look like `sk-ant-...`)
4. Keep this handy - you'll paste it into the tool

### Step 2: Open the Tool
1. Find the file `persona-generator.html` in this folder
2. **Double-click it** - it will open in your web browser
3. That's it! No installation needed.

### Step 3: Generate Personas
1. Paste your API key in the first field
2. Describe your problem or challenge
3. Add any extra context (optional)
4. Click "Generate Personas"
5. Wait a few seconds while AI creates 4 unique personas
6. Read through each persona's perspective on your problem

## What You'll Get

Each persona includes:
- **Name and role** - who they are
- **Background** - their expertise and experience
- **Perspective** - how they view your problem
- **Key questions** - what they would ask or be concerned about

Your API key and information never leave your computer - everything runs in your browser.

Anthropic provides free credits for new accounts. Each persona generation costs less than $0.01.

## Troubleshooting

**"API request failed"** - Check that you copied your full API key correctly

**Nothing happens when I click** - Make sure you filled in the required fields (marked with *)

**Personas look weird** - Try refreshing and generating again, or add more context to your problem description
